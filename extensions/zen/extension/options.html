BetterWinControl

Starting local connection…

Zen stays ready for connection. Ask Codex to use BetterWinControl; the controller connects to the requested window automatically. Readiness alone does not inspect tabs or pages.

To allow page controls on a site, click the extension's toolbar button while visiting that site. Tab selection does not require a site grant. Existing site grants are remembered.

What is shared

When you authorize a task, tab titles, addresses, page content and control state may be sent to the local BetterWinControl controller and the Codex task using it. This extension has no analytics and sends nothing directly to a remote server. Password fields are excluded. Page content can still contain personal information.

Pause or Stop in the BetterWinControl preview ends or pauses the current control session. Zen remains ready for your next request. Disabling readiness here disconnects all sessions and prevents reconnection until you enable it again here or use the toolbar button. This choice survives browser restarts.

An action already submitted to the browser may finish. Disconnecting never closes your tabs.
